🎵 タイミング設定モード — できること

音源と歌詞から LRC ファイル（時刻つき歌詞）を作成します。一度作っておけば、Creator で動画を作るときに読み込むだけで歌詞同期できます。別の曲のタイミングだけ取りたいときもこのタブで完結。

  1. 音源ファイル（mp3 / wav / m4a）を選択、または このタブにドラッグ&ドロップ
  2. 歌詞テキストを下のエリアに貼り付け
  3. 「タイミング入力」を押して再生 → 各行の歌い始めで Space、間奏は Enter、戻る ←
  4. 「LRC 書き出し」でファイルをダウンロード

🎬 動画作成モード — できること

音源にビジュアライザーや歌詞・ロゴを重ねて SNSショート動画（webm）を録画します。タイトル・歌詞・ロゴはキャンバス上をドラッグで自由配置、12 種のフォントと 6 種のエフェクトで装飾できます。

  1. 音源ファイル（mp3 / wav / m4a）を選択、または このタブにドラッグ&ドロップ
  2. 歌詞同期したい場合は LRC ファイル（.lrc/.txt）をドロップ（Timing タブで作ったもの）
  3. 背景スタイル・アスペクト比を選ぶ（9:16 がショート向け）
  4. 右パネルの「テキスト / 演出 / ロゴ」で装飾を調整
  5. キャンバス右上の「✥ 配置編集」でドラッグして位置決め
  6. 「● 録画」で WebM 書き出し
