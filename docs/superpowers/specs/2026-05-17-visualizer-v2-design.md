# Audio Visualizer v2 設計書

**作成日:** 2026-05-17  
**ステータス:** レビュー待ち

---

## 概要

既存のオーディオビジュアライザーを全面リニューアル。**2つの独立したモード**（歌詞タイミング設定 / 動画作成）を持ち、スタイリッシュなUI、動画背景モード（複数クリップ・タイムライン編集）、フォント選択、テキスト自由配置、GitHub Pages公開を実現する。

---

## 1. アプリ全体構成

### 2つのモード（タブで切り替え）

```
┌─────────────────────────────────────────────────┐
│  🎵 Timing  │  🎬 Creator                       │  ← タブ
├─────────────────────────────────────────────────┤
│                                                 │
│  Timing モード  ─────  LRC ファイル書き出し       │
│  Creator モード ─────  録画・動画書き出し         │
│                                                 │
└─────────────────────────────────────────────────┘
```

| モード | 目的 | 入力 | 出力 |
|---|---|---|---|
| **Timing**（タイミング設定） | 歌詞に時刻を付ける | 音源 + 歌詞テキスト | LRCファイル |
| **Creator**（動画作成） | 映像を作って録画する | 音源 + LRC（任意） + 背景設定 | WebM録画 |

**ワークフロー例：**
- 初回: Timing → 歌詞タイミング作成 → LRC書き出し → Creator → LRC読み込み → 録画
- 2回目以降: Creator → LRC読み込み → 録画（Timingは不要）
- 別曲の歌詞だけ作りたい: Timingだけ使う

### ファイル構成

```
Visualizer作成/
├── docs/                   # GitHub Pages 公開ルート
│   ├── index.html          # アプリ本体（タブUI）
│   ├── timing.js           # Timingモードロジック
│   ├── creator.js          # Creatorモードロジック
│   ├── shared/
│   │   ├── fonts.js        # フォント定義
│   │   ├── lyrics.js       # 歌詞描画（両モード共有）
│   │   └── audio.js        # AudioContext管理
│   └── styles/
│       ├── ui.css          # UIスタイル
│       └── visual/         # ビジュアルスタイル登録
├── README.md
└── .gitignore
```

GitHub Pages は `docs/` フォルダを公開ルートに指定する。

## 2. 背景モード構成（Creatorモード内）

**音声ファイルは常に必須。** 背景だけを切り替える。

| 背景 | 詳細 | ビジュアライザー | 歌詞/タイトル |
|---|---|---|---|
| **Visualizer**（デフォルト） | 黒 + スペクトラムエフェクト | ✓ あり | ✓ |
| **Video背景** | 複数動画クリップを順番再生 | なし | ✓ |

Creatorモード内のツールバートグルで切り替え。Video選択時にタイムラインパネルが展開する。

## 3. タイムライン（Videoモード）

### レイアウト

音声トラックと動画トラックを縦に並べたタイムライン表示。

```
[音声] ████████████████████████████████████  ← 全曲。トリムハンドルで前後をカット可
[動画] [clip_01 ████] [clip_02 ██████] [clip_03 ███] [＋ 追加]
```

### 機能
- **クリップ追加**: 動画トラック末尾の「＋ 追加」ボタン、またはドラッグ&ドロップ
- **並び順変更**: クリップをドラッグして入れ替え
- **トリム**: クリップ/音声の両端のハンドルをドラッグして in/out 点を設定
- **再生順**: 並び順通りに順番再生（ランダムなし）
- **音声トリム**: 開始・終了フレームをハンドルで調整
- クリップ間にギャップが生じた場合は黒フレームで補完

### データ構造

```js
// 音声
audio: { file, trimStart: 0, trimEnd: null }

// 動画クリップ（配列順に再生）
videoClips: [
  { id, file, trimStart: 0, trimEnd: null, duration }
]
```

## 4. テキスト自由配置

タイトル・歌詞それぞれ **キャンバス上でドラッグして位置を決める**。

- キャンバスに「テキスト配置モード」ボタン → ON にするとオーバーレイが編集モードになる
- タイトルブロック・歌詞ブロックをドラッグして好きな位置へ
- X/Y 座標はパーセンテージで保存（アスペクト比変更時も維持）
- 現行の `lyricsYSlider` は削除し、この UI に統合

## 5. テキスト装飾コントロール

タイトル・歌詞それぞれ個別に設定可能。

| コントロール | 詳細 |
|---|---|
| フォント | 12種から選択（選択UIにサンプルプレビュー付き） |
| フォントカラー | カラーピッカー（デフォルト: #ffffff） |
| フォントサイズ | スライダー（0.5x〜3x） |
| テキスト背景 | なし / 半透明バー / ぼかしブロック |
| シャドウ強度 | スライダー（0〜40px） |

## 5a. 歌詞エフェクト（選択式）

歌詞の行切り替わり時のアニメーションを選択式で提供。

| エフェクト名 | 動作 |
|---|---|
| **なし** | 即時切り替え（現行） |
| **フェードイン** | 新行が透明→不透明に 0.3s でフェード |
| **スライドアップ** | 新行が下から上にスライドしながらフェードイン |
| **タイプライター** | 1文字ずつ左から出現（日本語対応） |
| **グロー** | 音の強さ（bass）に合わせてグロー半径が脈打つ |
| **カラーシフト** | 音楽に合わせてフォントカラーがグラデーション変化 |

実装方法: Canvas上でアニメーション状態（`effectProgress`, `effectStartTime`）を管理し、各エフェクト関数が `drawLyricsOnCanvas` 内で呼び出される。行が切り替わるたびに `effectStartTime` をリセット。

## 5b. バンドロゴ表示

PNG / SVG / JPG の画像ファイルをキャンバス上の任意位置に固定表示。

### 機能
- **読み込み**: ファイルピッカー or ドラッグ&ドロップ（画像ファイル）
- **配置**: テキスト配置モードと同様にドラッグで位置決め（XY座標をパーセンテージ保存）
- **サイズ**: スライダーで幅を調整（アスペクト比は維持）
- **不透明度**: スライダー（0〜100%）
- **表示/非表示**: トグルスイッチ

### データ構造
```js
logo: {
  file: null,      // File オブジェクト
  img: null,       // HTMLImageElement
  x: 0.85,         // キャンバス幅に対する割合（デフォルト: 右下）
  y: 0.90,
  width: 0.15,     // キャンバス幅に対する割合
  opacity: 0.85,
  visible: true,
}
```

## 7. ビジュアルスタイル拡張（レジストリ方式）

新スタイルの追加を関数1つで完結させる。

```js
// styles/registry.js
const STYLE_REGISTRY = [];

export function registerStyle(id, label, drawFn) {
  STYLE_REGISTRY.push({ id, label, drawFn });
}

export function getStyles() { return STYLE_REGISTRY; }
```

```js
// styles/red-frame.js（既存スタイルの移植例）
import { registerStyle } from './registry.js';
registerStyle('red-frame', 'Red Frame + Wave', drawRedFrame);
function drawRedFrame(ctx, W, H, freq, time, bass, opts) { /* ... */ }
```

HTMLのスタイル選択ドロップダウンは `getStyles()` から自動生成。

## 8. オンボーディング（ステップガイドバー）

**Timingモード:**
```
① 音源を選択  →  ② 歌詞を貼り付け  →  ③ タイミング入力  →  ④ LRC書き出し
```

**Creatorモード:**
```
① 音源を選択  →  ② 背景を選ぶ  →  ③ 録画
```

- タブ切り替えで各モードのステップが独立して表示される
- 現在のステップが緑でハイライト、完了済みはチェックマーク付き
- 最終ステップ完了後は自動で折りたたみ（再表示ボタンあり）

## 9. UIリデザイン方針

- **カラーパレット**: 現行の `#0a0a0a` 黒ベース + `#1a9d52` グリーンを維持しつつ、グラデーション・glassmorphism を強化
- **タイポグラフィ**: Anton → Inter Variable に統一、日本語は Noto Sans JP
- **コントロール**: ピルボタン → より洗練したシャープ角丸。アイコン使用を増やす
- **パネル**: タイムライン・テキスト装飾・歌詞パネルをアコーディオンで統一
- **アニメーション**: パネル開閉・ステップ遷移に subtle なトランジション

## 10a. SNSショート動画向け機能

### イントロ/アウトロカード

録画前後に自動で表示するカードを設定可能。

- **イントロカード**: 録画開始時に2〜4秒間、曲名・バンド名を大きく表示してフェードアウト
- **アウトロカード**: 曲終了時に2〜4秒間、SNSハンドル・QRコードを表示
- **QRコード生成**: URL入力フィールドにSpotify/YouTube等のリンクを入力 → 自動でQRコード生成（`qrcode.js` 〜10KB）
- **ON/OFFトグル**: 各カード独立で無効化可能
- **表示秒数**: スライダーで調整（0〜6秒）

### プラットフォームプリセット

ワンクリックで該当プラットフォームの推奨設定を一括適用。

| プリセット | 設定内容 |
|---|---|
| **TikTok** | 9:16 / 1080×1920 / 60秒上限アラート / 上下UI干渉ゾーンを赤枠表示 |
| **Instagram Reels** | 9:16 / 1080×1920 / 90秒上限アラート / 右側UI干渉ゾーン表示 |
| **YouTube Shorts** | 9:16 / 1080×1920 / 60秒上限アラート / 下部のショート操作UIゾーン表示 |
| **Instagram Feed** | 1:1 / 1080×1080 / 上限なし |
| **YouTube** | 16:9 / 1920×1080 / 上限なし |

「テキスト安全域」はキャンバス上に半透明の赤枠でオーバーレイ表示。**録画には含まれない**（プレビュー専用）。

### スマホフレームプレビュー

プレビューパネルにiPhone/Androidフレームを重ねるトグル。

- ステージ右側に小型のフレームプレビューを表示（メインキャンバスは並列で表示）
- フレームの種類: iPhone 15 Pro / Pixel 8 / なし
- TikTok・Instagram・YouTube ShortsのUIスケルトン（コメントボタン・いいねボタンの位置）を半透明で重ねるオプションあり
- 「投稿時の実際の見え方」を視覚的に確認できる

## 10b. UI整理方針（ごちゃつき防止）

機能数が多いため、Creatorタブ内のコントロールを **5つのセクションに分類**し、アコーディオンで折りたたみ可能にする。

```
┌─ Creator タブ ──────────────────────────────────┐
│ ステップガイドバー                                │
│ ┌─────────────────┬──────────────────────────┐ │
│ │                 │ ▼ 📁 ソース                │ │
│ │                 │   音源・LRC・動画クリップ      │ │
│ │   キャンバス     ├──────────────────────────┤ │
│ │   プレビュー     │ ▼ 🎨 背景                  │ │
│ │                 │   Visualizer/Video + スタイル │ │
│ │   [▶ ⏸ ⏺]      ├──────────────────────────┤ │
│ │                 │ ▼ 📝 テキスト              │ │
│ └─────────────────┤   タイトル・歌詞・ロゴ        │ │
│                   ├──────────────────────────┤ │
│                   │ ▼ ✨ 演出                  │ │
│                   │   歌詞エフェクト・イントロ/アウトロ │
│                   ├──────────────────────────┤ │
│                   │ ▼ 📱 出力                  │ │
│                   │   プリセット・プレビュー・録画 │ │
│                   └──────────────────────────┘ │
└────────────────────────────────────────────────┘
```

- デフォルトでは「ソース」だけ展開、他は折りたたみ
- 各セクションのヘッダーに概要バッジ（例: `テキスト: タイトルON / 歌詞ON / ロゴOFF`）
- ステップガイドが進むと該当セクションが自動展開
- スマホ・タブレットでも崩れないレスポンシブ設計

## 11. 録画・書き出し（MP4直接出力）

### 方式

**WebCodecs API + mp4-muxer**（〜50KB）でブラウザ内MP4直接生成。

| ブラウザ | 対応状況 |
|---|---|
| Chrome 94+ / Edge 94+ | ✓ MP4直接出力 |
| Safari 16.4+ | ✓ MP4直接出力 |
| Firefox | △ WebMにフォールバック（ffmpegコマンド案内） |

### 実装方針

```js
// WebCodecs対応チェック
if (typeof VideoEncoder !== 'undefined') {
  // VideoEncoder (H.264) + AudioEncoder (AAC) → mp4-muxer → MP4 blob
  recordWithWebCodecs();
} else {
  // 従来のMediaRecorder → WebM
  recordWithMediaRecorder();
}
```

### 録画フロー（WebCodecsモード）

1. `canvas.captureStream(60)` で映像フレームを取得
2. `VideoEncoder` で H.264 にエンコード
3. `AudioEncoder` で AAC にエンコード
4. `mp4-muxer` でMP4コンテナに多重化
5. 録画終了時に MP4 Blob をダウンロード（`曲名-visualizer.mp4`）

### フォールバック（WebM）

WebCodecs非対応ブラウザでは従来通りWebM録画し、完了後に変換コマンドを表示：
```
ffmpeg -i input.webm -c:v libx264 -c:a aac output.mp4
```
